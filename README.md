# python-ml-fundamentals

A small, hands-on collection of Python fundamentals and introductory machine-learning examples.

## Tutorials

- [October 9: Python fundamentals and feature scaling](october-9/README.md) - language basics, dictionary operations, and a min-max feature scaling example.

## Run the example

Use Python 3 to run the tutorial script:

```bash
python3 october-9/my-file.py
```

The script uses only the Python standard library. Most fundamentals examples are kept as comments so they can be enabled and explored individually.
